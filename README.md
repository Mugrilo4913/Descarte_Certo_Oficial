# ♻️ DescarteCerto

🌐 Acesse a organização oficial do projeto:
https://github.com/DC-DescarteCerto

O **DescarteCerto** é uma aplicação web (PWA - Progressive Web App) desenvolvida para transformar a gestão de resíduos sólidos domésticos por meio da tecnologia e da informação. 

Este projeto nasceu como uma Ação Curricular de Extensão (ACEX) / Projeto Aplicado, criado por estudantes do curso de **Ciência da Computação do Centro Universitário Fundação Santo André (CUFSA)**, com foco inicial na região de Santo André (SP).

Nosso objetivo é combater a assimetria informacional sobre reciclagem, ajudando a população a descartar seus resíduos corretamente, encontrar ecopontos e promover um impacto positivo no meio ambiente, alinhado aos **Objetivos de Desenvolvimento Sustentável (ODS 11 e 12) da ONU**.

---

## ✨ Funcionalidades Principais

- 📷 **Scanner Inteligente de Resíduos:** Utilize a câmera do celular ou envie uma foto da galeria para que a nossa Inteligência Artificial identifique o material e diga exatamente como ele deve ser descartado.
- 🗺️ **Mapa de Descarte:** Um mapa interativo que localiza Ecopontos, Pontos de Entrega Voluntária (PEVs) e locais de coleta seletiva próximos ao seu CEP.
- 📚 **Guia de Categorias:** Informações detalhadas sobre como separar e limpar dezenas de tipos de materiais, incluindo Plástico, Papel, Vidro, Metal, Eletrônicos, Orgânicos, Resíduos de Saúde e até Materiais Radioativos.
- 📝 **Blogs e Dicas:** Guias rápidos e práticos para não errar no dia a dia da coleta seletiva.
- ⚙️ **Gestão de Perfil:** Configurações de conta, preferências de CEP para o mapa e controles de privacidade.

## 🛠️ Como rodar o projeto localmente (Download e Instalação)

Para baixar e rodar o **DescarteCerto** na sua máquina, siga o passo a passo abaixo. Certifique-se de ter o [Node.js](https://nodejs.org/) instalado.

### 1. Clone o repositório ou baixe os arquivos
Se estiver usando o Git, clone o repositório no seu terminal:
```bash
git clone https://github.com/DC-DescarteCerto/DescarteCerto.git
cd descartecerto
```
*(Se você baixou o arquivo `.zip`, basta extraí-lo e abrir a pasta no seu terminal).*

### 2. Instale as dependências
Com o terminal aberto na raiz do projeto (onde fica o arquivo `package.json`), instale todas as bibliotecas necessárias executando:
```bash
npm i
```
*(Opcional: você também pode usar `yarn install` ou `pnpm install` se preferir).*

### 3. Rode o servidor de desenvolvimento
Após a instalação terminar, inicie o projeto executando:
```bash
npm run dev
```

### 4. Acesse no navegador
Abra o seu navegador de preferência e acesse o endereço padrão do Next.js:
👉 **[http://localhost:3000](http://localhost:3000)**

Pronto! Agora você já pode navegar pelo aplicativo, testar o scanner, acessar o mapa e conferir as categorias de descarte.
